- Global Unified Design Pattern: Ensure the UI and Frontend across ALL apps (Rider, Vendor, Customer, Admin) follow a single, unified, and consistent design pattern (shared color palette, typography, button styles, input fields, form layouts, and spacing layouts). The look and feel must be uniform, professional, and completely optimized for each specific platform.
- Strict Role-Isolated Functionality: Code must strictly enforce that each panel ONLY executes functions meant for its specific role. 
  * Rider App must ONLY contain and execute Rider-specific functions (e.g., delivery status, navigation hooks).
  * Vendor Panel must ONLY execute Vendor-specific functions (e.g., product inventory, store metrics).
  * Customer App must ONLY execute Customer-specific functions (e.g., cart, checkout, browsing).
  * Admin Panel holds top-level control. Absolute zero role-leakage or cross-calling of unauthorized functions allowed.
- Smart User-Friendly Registration Forms: Audit the registration onboarding flow. Ensure that only ultra-critical fields are marked as Mandatory (e.g., Name, Phone/Email, Password). Technical documents or detailed profile files must be marked as Optional or deferred to post-registration to maximize conversion and user-friendliness.
- Professional Rate Limiting: Implement production-grade rate limiting (e.g., Express-Rate-Limit / Redis) on Login, Registration, and Forgot Password endpoints. The UI must handle this gracefully: if a user exceeds limit, display a professional countdown timer (e.g., "Too many attempts. Please try again in 5:00 minutes") instead of a raw system crash.
- Independent Task - Location & Device Metadata Tracking: Create a completely separate, modular service that automatically captures the user's Device Details (Browser/OS version, Device Type) and Location Meta-Data (IP address, Geolocation coords if permitted) during both Login and Registration actions. This data must be securely mapped to the user session/audit logs on the backend without blocking the auth lifecycle. Implement robust try-catch blocks so if geolocation is denied, the system fallbacks to IP tracking safely without crashing the UI.
